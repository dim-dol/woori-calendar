📱 안드로이드 휴대폰

갤럭시 등 안드로이드 휴대폰에서 받아요. (아이폰은 아직 지원하지 않아요)

앱 받기 (APK)
  1. 위 버튼을 누르고 다운로드가 끝나면 열기
  2. "출처를 알 수 없는 앱" 안내가 나오면 설정 → 이 출처 허용 켜고 돌아와 설치
  3. "Play 프로텍트" 경고가 나오면 세부정보 → 무시하고 설치
    (가족끼리 쓰려고 직접 만든 앱이라 구글 심사를 받지 않아서 나오는 안내예요)
  4. 앱을 열고 카카오로 계속하기로 로그인
  5. 받은 초대 링크를 누르면 가족 캘린더에 참여돼요
알림이 제때 오게 하려면: 설정 → 애플리케이션 → 드림 캘린더 → 배터리 "제한 없음"

💻 윈도우 PC

바탕화면에 띄워 두는 PC용 앱이에요.

PC 앱 받기 (zip)
  1. 받은 zip 파일을 마우스 오른쪽 클릭 → 압축 풀기 (원하는 곳에, 예: 문서 폴더)
  2. "드림캘린더" 폴더 안의 dream_calendar.exe 실행
  3. "Windows의 PC 보호" 파란 창이 나오면 추가 정보 → 실행
  4. 카카오로 계속하기로 로그인 (휴대폰과 같은 계정)
새 버전이 나오면 앱 위쪽에 알림이 떠요. 같은 폴더에 새로 받은 파일을 덮어써서 압축을 풀면 돼요.
문의는 앱을 보내준 가족에게 해 주세요 🙂
